\section{Conclusion}

This project set out to address the limitations of traditional Procedural Content Generation (PCG) by implementing a Genetic Algorithm (GA) designed 
to optimize dungeon layouts for player 'Flow'. The results indicate that treating level generation as an optimization problem allows for the 
creation of content that can support better balance challenge and player skill compared to static generation methods. By utilizing fitness 
functions grounded in engagement metrics, the developed system successfully generated playable and adaptive dungeon layouts, supporting the 
initial hypothesis.

The implications of this research extend to the broader field of Experience-Driven Procedural Content Generation (EDPCG). We demonstrated that 
evolutionary computation can be effectively utilized for offline Dynamic Difficulty Adjustment, reducing the risk of generating unfairly difficult 
or trivially easy content. This approach offers a robust framework for developers seeking to maximize replayability while maintaining a consistent 
quality of user experience.

Future research avenues include the integration of machine learning models to dynamically refine fitness functions based on real-time player 
telemetry. Furthermore, expanding the genetic representation to include more complex architectural features and enemy behaviors could yield 
even more diverse and personalized gameplay experiences. Ultimately, this work contributes to the ongoing effort to create games that intelligently 
adapt to their players.
