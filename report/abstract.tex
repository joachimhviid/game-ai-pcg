\begin{abstract}
Procedural Content Generation (PCG) is widely used to enhance replayability in games, yet traditional stochastic methods often 
struggle to consistently produce content that matches player skill levels, potentially disrupting the state of 'Flow'. This project 
investigates an Experience-Driven PCG (EDPCG) approach by implementing a Genetic Algorithm (GA) to optimize dungeon layouts in MiniDungeons. 
By treating level generation as an evolutionary optimization problem rather than a constructive process, the system evolves dungeon 
populations using fitness functions grounded in engagement metrics. This methodology effectively serves as an 
offline Dynamic Difficulty Adjustment (DDA) system, mitigating the risks of generating trivially easy or unfairly difficult content. The 
results indicate that the developed GA successfully produces playable and adaptive level structures that better balance challenge and skill 
compared to standard random generation. These findings suggest that evolutionary computation offers a better framework for developers 
aiming to maximize replayability while ensuring a consistent and engaging user experience.
\end{abstract}
